# Отзывы

Программа для Windows: вводите отзывы (текст + картинки .webp), потом преобразуете картинки в JPEG и листаете готовые отзывы, перетаскивая картинки мышкой куда нужно.

## Скачать

Готовый `Reviews.exe` собирается автоматически:
**Actions → последний запуск «Build Windows exe» → Artifacts → Reviews-windows** (внутри zip с exe).
Для версий с тегом `v*` exe также прикладывается к **Releases**.

Python устанавливать не нужно. Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее → Выполнить в любом случае».

## Как пользоваться

1. **Выберите товар** вверху (поле «Товар»). Кнопки рядом: ＋ новый товар, ✎ переименовать, ✕ удалить.
   Отзывы ведутся отдельно для каждого товара.
2. **Вкладка «Ввод отзывов»**
   - Впишите текст отзыва.
   - Добавьте картинки любым способом:
     - перетащите файлы из проводника;
     - перетащите картинку **прямо из браузера**;
     - в браузере правый клик → «Копировать картинку», затем **Ctrl+V** в программе;
     - кнопка «Добавить…».
   - **«Сохранить и следующий» (Ctrl+Enter)** — открывается чистая форма.
   - Слева список отзывов товара: можно вернуться к любому и исправить. Delete — удалить выбранные картинки.
   - Всё сохраняется автоматически.
3. **«Преобразовать в JPEG»** — картинки переводятся в .jpg (прозрачный фон → белый) и раскладываются по папкам.
4. **Вкладка «Просмотр»**
   - Листайте стрелками ← →, PgUp/PgDn или кликом в списке.
   - **Перетащите картинку мышкой** в браузер, мессенджер, папку — уйдёт файл `.jpg`.
   - Правый клик — скопировать картинку; «Копировать текст» — текст отзыва.

## Папки

Данные лежат в папке `ReviewsData` рядом с `Reviews.exe` (если туда писать нельзя — `Документы\ReviewsData`).
Готовые картинки — в `ReviewsData\Отзывы`:

```
Отзывы\
  Чайник Bosch\
    Отзыв 1\
      Чайник Bosch 1.jpg
      Чайник Bosch 2.jpg
      Текст отзыва.txt
    Отзыв 2\
      Чайник Bosch 1.jpg
      Текст отзыва.txt
  Кружка\
    Отзыв 1\ ...
```

Папку `Отзывы` программа держит в актуальном виде сама: при удалении отзыва или фото номера пересчитываются,
лишние `.jpg`/`.txt` удаляются. Поэтому свои файлы туда не кладите.
Исходные картинки хранятся в служебной папке `_исходники`. Чтобы перенести всё на другой компьютер — скопируйте `ReviewsData` целиком.

## Новая версия

Actions → «Build Windows exe» → Run workflow → в поле версии впишите, например, `v1.2.0`.
Сборка сама создаст релиз с `Reviews.exe`.

## Для разработки

```bash
pip install -r requirements.txt
python main.py            # можно указать свою папку данных: python main.py D:\мои_отзывы
pytest -q
```
