# Отзывы

Программа для Windows: вводите отзывы (текст + картинки .webp), потом преобразуете картинки в JPEG и листаете готовые отзывы, перетаскивая картинки мышкой куда нужно.

## Скачать

Готовый `Reviews.exe` собирается автоматически:
**Actions → последний запуск «Build Windows exe» → Artifacts → Reviews-windows** (внутри zip с exe).
Для версий с тегом `v*` exe также прикладывается к **Releases**.

Python устанавливать не нужно. Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее → Выполнить в любом случае».

## Как пользоваться

1. **Вкладка «Ввод отзывов»**
   - Впишите текст отзыва.
   - Перетащите картинки из проводника в окно (или кнопка «Добавить картинки…»). Можно сколько угодно.
   - **«Сохранить и следующий отзыв» (Ctrl+Enter)** — открывается чистая форма.
   - Слева список: можно вернуться к любому отзыву и исправить его. Delete — удалить выбранные картинки.
   - Всё сохраняется автоматически.
2. **«Преобразовать в JPEG»** — все картинки конвертируются (прозрачный фон → белый), открывается просмотр.
3. **Вкладка «Просмотр»**
   - Листайте кнопками ◀ ▶, PgUp/PgDn или кликом в списке.
   - **Перетащите картинку мышкой** в браузер, мессенджер, папку — уйдёт файл `.jpg`.
   - Правый клик — скопировать картинку в буфер; «Копировать текст» — текст отзыва.

## Где хранятся данные

Папка `ReviewsData` рядом с `Reviews.exe` (если туда писать нельзя — `Документы\ReviewsData`).
Кнопка «Открыть папку с данными» открывает её. Чтобы перенести отзывы на другой компьютер — скопируйте эту папку.

## Для разработки

```bash
pip install -r requirements.txt
python main.py            # можно указать свою папку данных: python main.py D:\мои_отзывы
pytest -q
```
